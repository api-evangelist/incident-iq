# Incident IQ

> Incident IQ is a K-12-purpose-built IT service management (ITSM) and asset management platform for school districts — help desk ticketing, device/technology asset tracking, facilities and HR service delivery, and analytics. Its RESTful API v1.0 supports custom integrations across the district ecosystem, with rule-triggered webhooks for pushing events to external systems. Requests use SiteId, Authorization (bearer token), and Client (ApiClient) headers issued from Administration > Developer Tools.

## APIs

- [Incident IQ API v1.0](https://apihub.incidentiq.com/): RESTful API — tickets, assets, users, locations, views, categories. Base path /api/v1.0 on the district's own incidentiq.com tenant host.
